Getting started & requirements

Run on a Linux server with Python 3.10+, Docker Engine and Docker Compose v2 installed. Keep n8n.sh and n8n_manager.py in the same directory, then run bash n8n.sh.

Select 2 to check prerequisites, then 1 for guided installation. HTTPS requires a domain pointing to the server and open inbound TCP ports 80 and 443. Without a domain, use an SSH tunnel for local-only access.

Backups and updates briefly stop n8n. Backups contain sensitive information and must be stored securely. Create the n8n owner account immediately after installation. Docker installation, firewall changes and automatic recovery are not performed by this tool.
